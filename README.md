# 生活自立學習站（學生練習版）

此網站提供學生在平板進行第 1、2 週生活技能練習。學生與家長使用同一個網站，不必設定教師密碼。

- 學生網站：https://yotindo0808.github.io/life-skills-learning/
- 教師修改開放進度：https://github.com/yotindo0808/life-skills-learning/edit/main/course-config.json

## 教師如何開放下一天

1. 由具有本 GitHub 儲存庫寫入權限的教師登入 GitHub。
2. 開啟上方的「教師修改開放進度」連結，點右上方的鉛筆編輯。
3. 找到 `"maxDay1": 1`：數字 1 代表第 1 週只開放到第 1 天。改成 2，即開放至第 2 天。合法範圍為 1 到 7。
4. 要開放第 2 週時，將 `"week2": false` 改為 `"week2": true`，再調整 `"maxDay2": 1` 至 1 到 7 天。
5. 按 **Commit changes** 儲存；GitHub Pages 完成部署後，學生在平板重新開啟網站即可取得新的設定。

## 其他設定

- `help`：`classroom` 表示第 2 週求助新技能暫留在課堂；`routine` 表示加入第 2 週每日練習題庫。
- `seq`：`true` 表示核心練習依序開放；`false` 表示不限制區塊順序。
- `speed`：語音朗讀速度，現行值為 `0.85`。

請維持 JSON 格式，勿刪除大括號、逗號、雙引號或將 `true`／`false` 加上引號。若設定檔無法讀取或格式錯誤，網站將只開放第 1 週第 1 天。

## 家長與學生

請家長使用上方「學生網站」連結。學生版沒有教師設定齒輪，也沒有自行設定 PIN 的入口，日後由教師統一控制網站上可點選的天數。每次開啟網站或切回網站視窗時，會更新教師設定。

學生學習紀錄僅存於各自裝置的瀏覽器，沒有雲端成績同步；更換平板或清除網站資料可能導致紀錄遺失。

**重要限制：** 這是公開的 GitHub Pages 靜態網站，介面層級的課程鎖定不是完整的身分驗證。技術使用者仍可查看公開程式碼中的未開放題目。若要限制所有方式存取未開放內容，必須使用伺服器端驗證與權限控制。請不要把學生真實姓名、家長電話等個資放入公開檔案。
