# 生活自立學習站

本網站提供第一、二週功能性生活技能自主練習，適用於平板瀏覽器。

## 啟用 GitHub Pages

在本儲存庫 Settings → Pages → Build and deployment，選擇 Source: Deploy from a branch，Branch: main、/(root)，按 Save。

網站網址：https://yotindo0808.github.io/life-skills-learning/

## 注意

網站內容為模擬教學資料。教師設定與學生進度儲存在各裝置的瀏覽器中，沒有雲端同步。教師 PIN 並非伺服器身分驗證。不要把真實學生個資寫進公開原始碼。
